# Моделирование детерминированного сигнала и построение его характеристик
- **signal_simulation.m** - моделирование гармонического сигнала линейно-частотной модуляции с девиацией частоты 
- **energy_and_average_power.m** - расчет энергетических характеристик и средней мощности сигнала
- **amplitude_spectrum.m** - построение амплитудного спектра
- **energy_spectrum.m** - построение энергетического спектра
- **power_spectrum.m** - построение спектра мощности
- **spectral_power_function.m** - построение функции спектральной мощности сигнала
